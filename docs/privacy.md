# プライバシーポリシー

運営者・連絡先: X @TommyZ794685

## 取得する情報
- サーバログ: 接続元IPアドレス、接続時刻、配信キー (パス名)、送受信バイト数、User-Agent等。
- アカウント登録はないため、氏名・メール等の個人特定情報は取得しない。

## 利用目的
- 障害対応、不正利用・荒らし対応、通信量集計、品質改善。

## 保持期間
- コンテナログ: 10MB x 3世代でローテーション (数日程度)。
- VM上のcronログ (`traffic-cron.log`, `watchdog-health.log`): 運用上必要な期間。定期的に削除する。
- 公開通信量ページはホスト合計値のみで、個人を特定できる情報を含まない。

## 第三者提供
- 法令に基づく場合を除き提供しない。インフラ (Oracle Cloud、Cloudflare) 上で処理される。
